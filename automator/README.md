# PDF → JPG для Finder

Быстрое действие Automator для одного или нескольких выделенных PDF. Работает на
встроенных macOS PDFKit и JavaScript for Automation: Homebrew, Python и Xcode для
запуска установленного действия не нужны.

## Установка

Скачайте `PDFtoJPG.workflow.zip` из [последнего релиза](https://github.com/joshuan/pdf-builder/releases/latest),
распакуйте и откройте `PDF to JPG.workflow` двойным кликом, чтобы установить действие.

Или из корня проекта:

```sh
make install-pdf-to-jpg
```

Или соберите `make pdf-to-jpg`, откройте `dist/PDF to JPG.workflow` двойным кликом
и установите быстрое действие. Весь скрипт встроен в workflow; после установки
папка проекта ему не нужна.

## Использование

Выделите PDF в Finder → правый клик → **Быстрые действия / Службы →
PDF to JPG**.

Для `Документ.pdf` рядом появятся `Документ-001.jpg`, `Документ-002.jpg` и т. д.
Если хотя бы одно имя занято, весь набор получит следующий свободный суффикс:
`Документ (2)-001.jpg`, `Документ (2)-002.jpg`. Существующие файлы сохраняются.

Страницы сохраняются с целевым разрешением **300 dpi**, качеством JPEG **95%**,
белым фоном, видимыми аннотациями, обрезкой и поворотом страницы из PDF.
Большие страницы автоматически уменьшаются с сохранением пропорций до **6000
пикселей по стороне и 24 мегапикселей**. Это также позволяет обрабатывать сканы,
у которых пиксельные размеры фотографии записаны как размеры страницы PDF.
Для уменьшенных страниц метаданные JPG содержат фактическое, более низкое dpi.

Для каждого PDF все страницы сначала записываются и проверяются во временной
папке рядом с исходником, затем переносятся на место. **Только после этого PDF
отправляется в системную корзину.** При ошибке конвертации исходник остаётся.
Если корзина недоступна, остаются и JPG, и PDF, а действие сообщает об ошибке.
Ошибка одного PDF не мешает обработке остальных выбранных файлов.

PDF с паролем и страницы с неверными размерами не обрабатываются.
Символические ссылки не принимаются. Для сохранения страниц
нужны права записи в папку исходного PDF. При аварийном завершении может остаться
скрытая временная папка `.pdf-to-jpg-…`; исходник при этом сохраняется до успешной
публикации всех страниц.

## Изменение настроек

Откройте установленное действие в Automator. В действии **Run Shell Script**
измените `DPI = 300`, `JPEG_QUALITY = 0.95`, `MAX_PAGE_EDGE = 6000` или
`MAX_PAGE_PIXELS = 24000000`, затем сохраните. Настройки также
есть в `automator/pdf-to-jpg.js`; после изменения исходника повторите установку.

Параметры Automator: вход **PDF files** в **Finder**, оболочка **/bin/zsh**,
передача входных данных **as arguments**. Действие должно принимать выделение
непосредственно; добавлять «Get Selected Finder Items» не требуется.

Если пункт скрыт, включите его в настройках служб macOS. Подробнее:
[быстрые действия в Automator](https://support.apple.com/guide/automator/aut73234890a/mac),
[отрисовка PDFPage](https://developer.apple.com/documentation/pdfkit/pdfpage).

## Проверка

```sh
make test-pdf-to-jpg
```

Проверки используют только созданные ими PDF во временной папке. Вместо
системной корзины тесты используют отдельную тестовую папку, проверяя порядок
действий, ошибки сохранения и невозможность перезаписи существующих файлов.
